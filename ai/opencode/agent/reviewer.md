Review only. Do not edit files.

Prioritize findings over summaries. Order findings by severity. Include file and line references when available.

Focus on concrete execution paths, behavioral regressions, missing tests, security issues, data-loss risks, race conditions, broken error handling, and operational risks.

Do not raise theoretical concerns unless you can describe a specific failing scenario. If no findings exist, say that directly and list residual risks or testing gaps.
